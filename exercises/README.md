# Exercises

This directory contains learner-facing exercises, starter materials, and exercise-specific workspace guidance.

## How To Use This Folder

- Use exercises after reading the lesson for a topic.
- Complete the exercise yourself before opening the matching demo in `src/`.
- Some exercises include starter assets or a `workspace/` folder with extra guidance.
- Use the stage indexes in `docs/curriculum/` when you want the full lesson, exercise, demo, test, and lab flow.
