# Challenge Brief

Build a console app named `PracticeCatalogConsole` that stores typed study resources in a generic catalog.

Your app must:

- define a small resource contract
- create a generic catalog class with a useful constraint
- use more than one collection type for different operations
- throw a standard exception for one invalid operation
- catch one specific exception at the application boundary and print a clear note

Keep the model small enough that the design decisions stay visible.
