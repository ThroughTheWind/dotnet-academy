# Exercise Starter Pack

This folder contains the learner starter assets for the `03-interfaces-and-composition` topic.

The goal is to help the learner define one clean abstraction and then compose multiple implementations into a useful plan.

## Contents

- `workspace/` is the recommended place to create the learner's practice project.
- `challenge-brief.md` summarizes the task.
- `expected-output.md` shows example output structure for self-checking.
- `micro-exercise.md` is the short focused drill for one interface and two implementations.
