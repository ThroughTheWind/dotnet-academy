# Expected Output Example

Your wording can differ, but the structure should look similar to this.

```text
Learning Plan
-------------
Learner: Avery
Total estimate: 50 minutes
Agenda:
- Interfaces for shared behavior (20 min video lesson)
- Compose a study plan from small parts (30 min practice exercise)
```

The important part is that the agenda items come from different classes that implement the same interface and are then composed into one plan object.
