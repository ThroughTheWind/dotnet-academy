# Expected Output Example

Your wording can differ, but the structure should look similar to this.

```text
Study Group Summary
-------------------
Member: Avery
Completed topics: 3
Summary: Avery is ready for the next object-modeling exercise.

Member: Mina
Completed topics: 1
Summary: Mina should repeat one small class exercise before moving on.
```

The important part is that the member data comes from objects and that at least one method on the class produces part of the displayed summary.
