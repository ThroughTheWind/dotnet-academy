# Expected Output Example

Your wording can differ, but the structure should look similar to this.

```text
Resource Planner
----------------
Composition over inheritance (25 min guided lesson on abstraction choices)
Follow-up: Review the key idea once before moving on.
Refactor a base type carefully (30 min challenge, 2 expected outputs)
Follow-up: Run the challenge again with a different input set.
```

The important part is that both lines come from derived types used through the shared base type.
