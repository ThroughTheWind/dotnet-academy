# Expected Output Example

Your wording can differ, but the structure should look similar to this.

```text
Milestone Tracker
-----------------
Original milestone: Records and value semantics (In progress)
Updated milestone: Records and value semantics (Completed)
Practice budget: 3/5 sessions completed, 2 sessions remaining.
Preferred review label: Needs review
```

The important part is that the status comes from an enum, the updated milestone comes from a record copy, and the budget summary comes from a struct.
