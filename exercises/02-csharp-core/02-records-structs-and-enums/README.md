# Exercise Starter Pack

This folder contains the learner starter assets for the `02-records-structs-and-enums` topic.

The goal is to help the learner distinguish between three compact modeling tools without turning the exercise into a large application.

## Contents

- `workspace/` is the recommended place to create the learner's practice project.
- `challenge-brief.md` summarizes the task.
- `expected-output.md` shows example output structure for self-checking.
- `micro-exercise.md` is the short focused drill for one enum and one record copy.
