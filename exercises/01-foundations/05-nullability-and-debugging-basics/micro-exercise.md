# 05 Nullability And Debugging Basics Micro Exercise

## Prompt

Declare `string? mentorName = null;` and print a safe display value using either `??` or a null check.

Then print a short three-step debugging checklist that tells a learner what to inspect before changing code.

## Constraints

- Keep the example text-based and small.
- Use one explicit nullable text variable.
- Keep the checklist concrete rather than generic.

## Verification

You are done when the app shows both the fallback display and three debugging steps that another beginner could actually follow.
