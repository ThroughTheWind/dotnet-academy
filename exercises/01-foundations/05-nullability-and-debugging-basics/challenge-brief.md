# Challenge Brief

Build a console app named `LearnerSupportConsole`.

## Requirements

- Use at least one nullable `string?` value.
- Show a safe fallback when the optional value is missing.
- Print a short learner support summary.
- Include a debugging checklist with at least three steps.
- Keep the app focused on nullability and debugging basics.

## Suggested Run Command

```powershell
dotnet run
```
