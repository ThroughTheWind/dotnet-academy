# Expected Output Example

Your wording can differ, but the structure should look similar to this.

```text
Learner Support Summary
-----------------------
Mentor: no mentor assigned
Recent warning: possible null value detected
Debugging checklist:
- Reproduce the same behavior
- Inspect the current values
- Confirm where the value changed
```

The important part is that missing values are handled safely and that the debugging advice is specific enough to follow.
