# Exercise Starter Pack

This folder contains the learner-facing starter assets for the `01-development-environment-and-cli` exercise.

This topic intentionally does not provide a prebuilt project because the learner must practice creating the project with the CLI.

## Contents

- `workspace/` is the recommended place to create the learner's practice project.
- `reflection-template.md` is the answer sheet for the written verification questions in the exercise.
- `submission-checklist.md` is the final self-check before moving to the next topic.
- `micro-exercise.md` is the short focused drill for quick CLI and SDK verification practice.

## Suggested Workflow

1. Read the exercise instructions in `docs/curriculum/01-foundations/01-development-environment-and-cli/exercises.md`.
2. Open a terminal in `workspace/`.
3. Run the required `dotnet` commands there.
4. Fill in `reflection-template.md` after the project builds and runs successfully.
5. Use `submission-checklist.md` to verify you completed the exercise without skipping steps.
