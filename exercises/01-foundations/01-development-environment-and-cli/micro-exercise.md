# 01 Development Environment And CLI Micro Exercise

## Prompt

From a terminal, run the smallest set of commands needed to answer these questions:

1. Which .NET SDK version is currently active?
2. Which two project templates could you create next?
3. What file controls how a basic console project is built?

## Constraints

- Use the CLI only.
- Do not create a full project unless you need one to confirm the project file name.

## Verification

You are done when you can say the current SDK version, name two templates from `dotnet new list`, and identify the `.csproj` file as the project definition.
