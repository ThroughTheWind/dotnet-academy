# Exercise Starter Pack

This folder contains the learner starter assets for the `03-variables-types-and-conversions` topic.

The goal is to help the learner build their own typed console app while keeping the focus on variable choice, type clarity, and one simple conversion.

## Contents

- `workspace/` is the recommended place to create the learner's practice project.
- `challenge-brief.md` summarizes the task.
- `expected-output.md` shows example output structure for self-checking.
