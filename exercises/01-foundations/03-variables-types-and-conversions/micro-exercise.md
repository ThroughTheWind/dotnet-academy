# 03 Variables Types And Conversions Micro Exercise

## Prompt

Write a tiny console app block that declares:

- one `string`
- one `int`
- one `decimal`
- one `bool`

Then start with one numeric value as text, convert it into a number, and print all five values.

## Constraints

- Use clear variable names.
- Use either `int.Parse(...)` or `decimal.Parse(...)` for the conversion.
- Keep the output to five lines or fewer.

## Verification

You are done when the app runs successfully and you can explain why the original text value needed conversion before it could be used as a number.
