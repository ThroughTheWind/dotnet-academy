# Challenge Brief

Build a console app named `LearnerProgressCard`.

## Requirements

- Use a `string` for the learner name.
- Use an `int` for completed topics.
- Use a `decimal` for practice hours.
- Use a `bool` for readiness for the next topic.
- Start with one numeric value as text and convert it before printing it.
- Print a readable multi-line summary.

## Suggested Run Command

```powershell
dotnet run
```
