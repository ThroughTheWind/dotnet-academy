# Exercise Starter Pack

This folder contains the learner starter assets for the `04-control-flow-and-methods` topic.

The goal is to help the learner build their own small recommendation app while keeping the focus on decisions, loops, and methods.

## Contents

- `workspace/` is the recommended place to create the learner's practice project.
- `challenge-brief.md` summarizes the task.
- `expected-output.md` shows example output structure for self-checking.
