# Challenge Brief

Build a console app named `StudyDecisionConsole`.

## Requirements

- Use an `int` for completed topics.
- Use a `bool` for whether the learner practiced today.
- Write at least one method that returns a message.
- Use `if` and `else` to choose between recommendations.
- Use a `for` loop to print a short list of practice sessions.
- Print a readable multi-line summary.

## Suggested Run Command

```powershell
dotnet run
```
