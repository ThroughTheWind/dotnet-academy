# Expected Output Example

Your wording can differ, but the structure should look similar to this.

```text
Study Recommendation
--------------------
Completed topics: 3
Practiced today: False
Recommendation: Practice once today before moving on.
Suggested sessions:
- Practice session 1
- Practice session 2
- Practice session 3
```

The important part is that the recommendation changes based on the condition and that the repeated lines come from a loop.
