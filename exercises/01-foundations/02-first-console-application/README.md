# Exercise Starter Pack

This folder contains the learner starter assets for the `02-first-console-application` topic.

Unlike the runnable sample under `src/`, these assets are meant to support the learner while they create their own console app from scratch.

## Contents

- `workspace/` is the recommended place to create the learner's practice project.
- `challenge-brief.md` summarizes the task in short form.
- `expected-output.md` shows example output structures for validation.
