# Challenge Brief

Build a console app named `LearnerCardConsole`.

## Requirements

- Create the app with `dotnet new console`.
- Print a title line.
- Print `Hello, learner!` when no name is passed.
- Print `Hello, <name>!` when a name is passed.
- Print one line about what you are learning.
- Print one line about your current goal.

## Run Examples

```powershell
dotnet run
dotnet run -- Ada
```
