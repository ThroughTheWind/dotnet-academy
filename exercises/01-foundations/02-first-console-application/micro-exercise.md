# 02 First Console Application Micro Exercise

## Prompt

Create or reuse a small console app and make it print exactly two lines:

1. a title line
2. a greeting line that uses `learner` by default and changes when you run the app with one name argument

## Constraints

- Use top-level statements.
- Keep the app to two printed lines.
- Run it once without an argument and once with a name argument.

## Verification

You are done when you can run the app in both modes and explain which line in `Program.cs` controls the greeting output.
