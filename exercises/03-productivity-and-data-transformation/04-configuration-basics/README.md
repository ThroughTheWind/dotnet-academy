# Exercise Starter Pack

This folder contains the learner starter assets for the `04-configuration-basics` topic.

The goal is to help the learner understand provider order, binding, and validation in a small console-friendly example.

## Contents

- `workspace/` is the recommended place to create the learner's practice project.
- `challenge-brief.md` summarizes the task.
- `expected-output.md` shows example output structure for self-checking.
- `micro-exercise.md` is the short focused drill for one configuration override.
