# Expected Output Example

Your wording can differ, but the structure should look similar to this.

```text
Async Await Foundations Demo
----------------------------
Modules loaded: 3
Total minutes: 101
Modules needing attention:
- File exports: 3 pending sessions, 28 min total
- Configuration setup: 2 pending sessions, 41 min total
- LINQ review: 1 pending session, 32 min total
Async note: start independent work, await the tasks, and shape the finished results after completion rather than blocking with Result or Wait.
```

The important part is that the report comes from awaited tasks rather than from blocking calls.
