# Exercise Starter Pack

This folder contains the learner starter assets for the `05-async-and-await-foundations` topic.

The goal is to help the learner understand how to write and compose small asynchronous methods before layering in more advanced async tradeoffs.

## Contents

- `workspace/` is the recommended place to create the learner's practice project.
- `challenge-brief.md` summarizes the task.
- `expected-output.md` shows example output structure for self-checking.
- `micro-exercise.md` is the short focused drill for combining independent tasks.
