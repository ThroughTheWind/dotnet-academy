# Exercise Starter Pack

This folder contains the learner starter assets for the Stage 3 synchronous-versus-asynchronous-versus-streaming flow comparison exercise pack.

The goal is to push the learner to shape the same study digest three ways: once after fully synchronous loading, once after asynchronous batch loading, and once while consuming values from a stream, then explain the tradeoffs instead of treating one flow as automatically modern or correct.

## Contents

- `workspace/` is the recommended place to create the learner's practice project.
- `challenge-brief.md` summarizes the full comparison task.
- `expected-output.md` shows example output structure for self-checking.
- `micro-exercise.md` is the short focused drill for comparing buffered and streamed processing.
