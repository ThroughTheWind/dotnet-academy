# Expected Output Example

Your wording can differ, but the structure should look similar to this.

```text
Planning Board
--------------
Tracked categories: 3
Priority items:
- BOARD-02: Contrast dictionary lookups [collections]
- BOARD-03: Review snapshot boundaries [immutability]
- BOARD-04: Publish stable report models [reporting]
Category summary:
collections: 2 items
immutability: 1 items
reporting: 1 items
Snapshot before update: 1 complete, 3 remaining
Live board after update: 2 complete, 4 total
Snapshot still says: 1 complete, 3 remaining
```

The important part is that the report makes the mutable live board and the stable published snapshot visibly different.
