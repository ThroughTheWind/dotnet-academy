# Workspace Guidance

Create the learner exercise project in this folder so the starter assets and your code stay together.

Suggested commands:

```bash
dotnet new console -n PublishedGuideCatalogConsole
dotnet add ./PublishedGuideCatalogConsole package System.Collections.Immutable
dotnet run --project ./PublishedGuideCatalogConsole
```

After the first version runs, compare your behavior with `../expected-output.md`.
