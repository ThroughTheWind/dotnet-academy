# Exercise Starter Pack

This folder contains the learner starter assets for the `02a-immutable-read-only-and-frozen-collection-tradeoffs` topic.

The goal is to help the learner choose the right publication surface for callers: live read-only access, immutable snapshots, or frozen read-heavy lookups.

## Contents

- `workspace/` is the recommended place to create the learner's practice project.
- `challenge-brief.md` summarizes the task.
- `expected-output.md` shows example output structure for self-checking.
- `micro-exercise.md` is the short focused drill for read-only versus immutable behavior.
