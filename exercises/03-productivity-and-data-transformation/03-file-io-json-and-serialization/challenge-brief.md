# Challenge Brief

Build a console app named `StudyArchiveExportConsole` that reads a study-session file and exports a transformed result.

Your app must:

- load JSON from disk
- deserialize it into input models
- compute a summary export model
- write that export as JSON
- write a plain-text report next to it

Keep the design small enough that another learner can point to the input model, the transformation step, and the output model separately.
