# Exercise Starter Pack

This folder contains the learner starter assets for the `05a-cancellation-async-streams-and-valuetask-tradeoffs` topic.

The goal is to help the learner practice three related ideas without overgeneralizing them: cancellation should flow through asynchronous work, async streams should model values that arrive over time, and `ValueTask<T>` should stay limited to narrow cache-like scenarios.

## Contents

- `workspace/` is the recommended place to create the learner's practice project.
- `challenge-brief.md` summarizes the task.
- `expected-output.md` shows example output structure for self-checking.
- `micro-exercise.md` is the short focused drill for cancellation-aware async streams.
