# Challenge Brief

Build a console app named `ToolingReleaseBriefConsole` that prints a short build and packaging briefing for a sample .NET library.

Your app must:

- explain the pinned SDK version
- show the command order for restore, build, test, and pack
- identify the project properties that make the sample library packable
- print the expected Release output directory
- print the expected `.nupkg` artifact name

Keep the design small enough that another learner can point from each output line back to one command or one project property clearly.
