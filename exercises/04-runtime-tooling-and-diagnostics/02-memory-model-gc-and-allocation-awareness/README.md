# Exercise Starter Pack

This folder contains the learner starter assets for the `02-memory-model-gc-and-allocation-awareness` topic.

The goal is to help the learner compare transient allocations with retained objects in a small console-friendly example.

## Contents

- `workspace/` is the recommended place to create the learner's practice project.
- `challenge-brief.md` summarizes the task.
- `expected-output.md` shows example output structure for self-checking.
- `micro-exercise.md` is the short focused drill for distinguishing allocation volume from live managed memory.
