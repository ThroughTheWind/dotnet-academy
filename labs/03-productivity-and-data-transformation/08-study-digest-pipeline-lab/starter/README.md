# Lab Starter Pack

This folder contains the learner starter assets for the `08-study-digest-pipeline-lab` lab.

The goal is to help the learner combine the major Stage 3 ideas into one small but realistic pipeline without losing visibility into the loading, shaping, and output steps.

## Contents

- `workspace/` is the recommended place to create the learner's lab project.
- `challenge-brief.md` summarizes the lab task.
- `expected-output.md` shows one possible output shape for self-checking.
