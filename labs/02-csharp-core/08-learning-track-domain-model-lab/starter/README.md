# Lab Starter Pack

This folder contains the learner starter assets for the `08-learning-track-domain-model-lab` lab.

The goal is to help the learner design one small but realistic Stage 2 domain model without losing visibility into the language features behind it.

## Contents

- `workspace/` is the recommended place to create the learner's lab project.
- `challenge-brief.md` summarizes the lab task.
- `expected-output.md` shows one possible output shape for self-checking.
