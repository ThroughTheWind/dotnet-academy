# Challenge Brief

Build a console app named `DotnetAcademy.StudySessionPlannerLab` that prints a short study plan for a learner.

Your app must combine these Stage 1 skills:

- running a console app from the CLI
- reading a learner name from command-line arguments
- converting numeric text into numbers
- using helper methods and one decision branch
- generating an action list with a loop
- handling a missing optional value with a safe fallback

Keep the output readable and close to the structure in `expected-output.md`.
