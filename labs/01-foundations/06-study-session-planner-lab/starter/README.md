# Lab Starter Pack

This folder contains the learner starter assets for the `06-study-session-planner-lab` lab.

The goal is to help the learner build one small integrated console application without losing the beginner-friendly structure used across Stage 1.

## Contents

- `workspace/` is the recommended place to create the learner's lab project.
- `challenge-brief.md` summarizes the lab task.
- `expected-output.md` shows one possible output shape for self-checking.
