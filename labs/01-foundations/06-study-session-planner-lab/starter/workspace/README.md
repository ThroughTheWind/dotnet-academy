# Workspace Guidance

Create the learner lab project in this folder so the starter assets and your code stay together.

Suggested commands:

```bash
dotnet new console -n DotnetAcademy.StudySessionPlannerLab
dotnet run --project ./DotnetAcademy.StudySessionPlannerLab -- Ada
```

After the first version runs, keep iterating in small steps and compare your output with `../expected-output.md`.
