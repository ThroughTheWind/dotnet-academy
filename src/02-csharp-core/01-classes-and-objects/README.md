# Classes And Objects Sample

This folder contains the runnable sample for the `01-classes-and-objects` topic.

## Project

- `DotnetAcademy.ClassesObjectsDemo/` demonstrates one small class that groups learner state and behavior.

## Run The Sample

From the repository root:

```powershell
dotnet run --project ./src/02-csharp-core/01-classes-and-objects/DotnetAcademy.ClassesObjectsDemo
```

## What To Observe

- the sample creates an object from a class with a constructor
- instance methods update or summarize the object's state
- computed properties make the output easier to read
