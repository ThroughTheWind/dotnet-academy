# Inheritance Basics Sample

This folder contains the runnable sample for the `04-inheritance-basics` topic.

## Project

- `DotnetAcademy.InheritanceBasicsDemo/` demonstrates an abstract base class and two derived resource types.

## Run The Sample

From the repository root:

```powershell
dotnet run --project ./src/02-csharp-core/04-inheritance-basics/DotnetAcademy.InheritanceBasicsDemo
```

## What To Observe

- the sample uses base-type references to work with two derived types
- one derived type overrides a virtual follow-up action
- the final note explains why inheritance should stay deliberate and narrow
