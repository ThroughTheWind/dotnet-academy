# LINQ Fundamentals And Query Thinking Sample

This folder contains the runnable sample for the `01-linq-fundamentals-and-query-thinking` topic.

## Project

- `DotnetAcademy.LinqQueryThinkingDemo/` demonstrates filtering, projection, ordering, grouping, and readable query composition.

## Run The Sample

From the repository root:

```powershell
dotnet run --project ./src/03-productivity-and-data-transformation/01-linq-fundamentals-and-query-thinking/DotnetAcademy.LinqQueryThinkingDemo
```

## What To Observe

- the sample starts from plain-language data questions and maps them to small LINQ pipelines
- one query uses method syntax and another uses query syntax for grouping
- the output sections make it clear which query answered which question
