# Development Environment And CLI Sample

This folder contains the runnable sample for the first Stage 1 topic.

## Project

- `DotnetAcademy.CliBasicsDemo/` is a small console application that reinforces the difference between the runtime and the SDK, and points the learner back to the key files and commands introduced in the lesson.

## Run The Sample

From the repository root:

```powershell
dotnet run --project ./src/01-foundations/01-development-environment-and-cli/DotnetAcademy.CliBasicsDemo
```

## What To Observe

- The sample runs as a normal .NET 10 console project.
- `Program.cs` contains the executable source code.
- `DotnetAcademy.CliBasicsDemo.csproj` contains the project definition.
- `bin/` and `obj/` appear after build and run operations.
