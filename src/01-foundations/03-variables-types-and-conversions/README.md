# Variables Types And Conversions Sample

This folder contains the runnable sample for the `03-variables-types-and-conversions` topic.

## Project

- `DotnetAcademy.VariablesTypesDemo/` demonstrates simple typed variables and one text-to-number conversion in a console application.

## Run The Sample

From the repository root:

```powershell
dotnet run --project ./src/01-foundations/03-variables-types-and-conversions/DotnetAcademy.VariablesTypesDemo
```

## What To Observe

- the sample stores values in `string`, `int`, `decimal`, and `bool` variables
- one value starts as text and is converted into an integer
- the printed output includes both the variable meaning and the chosen type
