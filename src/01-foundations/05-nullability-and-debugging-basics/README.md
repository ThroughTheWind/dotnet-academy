# Nullability And Debugging Basics Sample

This folder contains the runnable sample for the `05-nullability-and-debugging-basics` topic.

## Project

- `DotnetAcademy.NullabilityDebuggingDemo/` demonstrates nullable text values, safe fallback behavior, and a short debugging checklist.

## Run The Sample

From the repository root:

```powershell
dotnet run --project ./src/01-foundations/05-nullability-and-debugging-basics/DotnetAcademy.NullabilityDebuggingDemo
```

## What To Observe

- the sample shows a raw nullable value and a safer display value
- the output uses fallback text instead of assuming optional values always exist
- the debugging checklist gives concrete next steps rather than vague advice
