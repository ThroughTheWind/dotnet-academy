# 12 Capstone

This stage brings the course together in an end-to-end production-style project.

## Outcomes

- Build a full system that combines APIs, data access, caching, testing, and a Blazor UI.
- Justify technical tradeoffs in architecture, performance, and delivery.
- Present a solution that is understandable, testable, observable, and maintainable.

## Planned Topics

- End-to-end planning and milestone breakdown
- Backend implementation
- Frontend implementation with Blazor
- Performance review, testing, and hardening
