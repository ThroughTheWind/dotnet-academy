# 04 Runtime Tooling And Diagnostics

This stage teaches how .NET programs are built, executed, observed, and optimized.

## Outcomes

- Explain the .NET SDK, build pipeline, and package flow.
- Understand garbage collection, allocations, spans, and runtime tradeoffs.
- Use logs, metrics, tracing, profilers, and debugger tooling to investigate behavior.

## Planned Topics

- SDK, runtime, and package management
- Garbage collection and allocation awareness
- Spans, buffers, and memory-sensitive APIs
- Logging, tracing, metrics, and profiling
- Concurrency, cancellation, and resilience basics
