# 07 Api Development

This stage turns ASP.NET Core knowledge into production-grade service development.

## Outcomes

- Design and implement REST APIs with current ASP.NET Core patterns.
- Choose between minimal APIs, controllers, gRPC, and SignalR based on the problem.
- Apply authentication, authorization, versioning, OpenAPI, and compatibility practices effectively.

## Planned Topics

- REST design and HTTP semantics
- Minimal APIs and controllers
- Authentication and authorization
- OpenAPI, contract evolution, pagination, filtering, and versioning
- gRPC, SignalR, and reliability tradeoffs
