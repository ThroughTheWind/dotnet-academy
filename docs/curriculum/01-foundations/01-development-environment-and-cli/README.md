# 01 Development Environment And CLI

## Goal

This topic gets a learner to a working .NET 10 development environment and teaches the minimum command-line workflow used throughout the rest of the course.

By the end of the topic, the learner should be able to:

- verify that the .NET SDK is installed correctly
- distinguish the SDK from the runtime at a practical level
- create, build, and run a console application from the terminal
- recognize the purpose of the key files the CLI generates

## Deliverables

- `lesson.md` contains the teaching material for environment setup and CLI basics.
- `exercises.md` contains a guided exercise that verifies the learner can use the SDK and CLI successfully.
- Runnable sample project: `src/01-foundations/01-development-environment-and-cli/DotnetAcademy.CliBasicsDemo/`.
- Learner starter assets: `exercises/01-foundations/01-development-environment-and-cli/`.
- Guided lab connection: `labs/01-foundations/06-study-session-planner-lab/` uses this topic as part of the first integrated Stage 1 project.
