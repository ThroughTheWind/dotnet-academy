# 01 Foundations

This stage introduces programming with modern C# and the .NET toolchain from a clean starting point.

## Outcomes

- Install and use the .NET SDK and CLI confidently.
- Write simple C# programs using variables, types, operators, control flow, and methods.
- Understand nullability, basic debugging, and common beginner mistakes.

## Planned Topics

- Development environment and .NET CLI basics
- First console applications
- Variables, types, operators, and conversions
- Control flow and methods
- Nullability and debugging basics
