# 05 Nullability And Debugging Basics

## Goal

This topic teaches the learner how to reason about values that may be missing, how to use safe fallback patterns, and how to debug a small console app without guessing.

By the end of the topic, the learner should be able to:

- explain what `string?` means in a beginner-friendly way
- use a null check or `??` to provide a safe fallback value
- identify simple signals that a variable may not contain the value the program expected
- follow a short debugging checklist before changing code at random
