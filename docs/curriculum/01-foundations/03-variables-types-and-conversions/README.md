# 03 Variables Types And Conversions

## Goal

This topic teaches the learner how to store values in variables, choose beginner-friendly built-in types, and perform simple conversions without losing track of what the program is doing.

By the end of the topic, the learner should be able to:

- declare variables with useful names
- choose basic types such as `string`, `int`, `decimal`, and `bool`
- explain the difference between a value and its type at a beginner level
- convert numeric text into numbers and reuse the converted value in code
