# 04 Control Flow And Methods

## Goal

This topic teaches the learner how a program makes decisions, repeats simple steps, and organizes reusable logic into methods.

By the end of the topic, the learner should be able to:

- use `if` and `else` to choose between outcomes
- explain simple boolean conditions in beginner-friendly terms
- write and call a small method with parameters and a return value
- use a basic loop to repeat a predictable step
