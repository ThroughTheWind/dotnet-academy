# 02 First Console Application

## Goal

This topic teaches the learner how a console app actually starts, how `Program.cs` works in a beginner-friendly .NET project, and how to modify the application so it behaves differently when run.

By the end of the topic, the learner should be able to:

- create and run a console application with the CLI
- explain the role of `Program.cs` and top-level statements
- modify program output and rerun the app confidently
- pass a simple command-line argument with `dotnet run -- <value>`
