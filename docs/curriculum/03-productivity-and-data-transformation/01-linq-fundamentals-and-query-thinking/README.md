# 01 LINQ Fundamentals And Query Thinking

## Goal

This topic teaches the learner how to ask clear questions about data and then express those questions with LINQ instead of nested loops and temporary variables.

By the end of the topic, the learner should be able to:

- explain how filtering, projection, ordering, and grouping answer different data questions
- build small LINQ pipelines that stay readable from left to right
- choose between method syntax and query syntax based on clarity
- materialize a query only when a concrete result is actually needed
