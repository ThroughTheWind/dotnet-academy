# 03 File IO JSON And Serialization

## Goal

This topic teaches the learner how to move data between in-memory models and files on disk using basic file APIs and JSON serialization without pulling in configuration or asynchronous workflows yet.

By the end of the topic, the learner should be able to:

- read text and JSON data from files safely
- deserialize JSON into explicit models, transform it in memory, and write exported results back to disk
- distinguish between the input model that was read and the output model that gets serialized
- choose simple file paths that avoid surprising writes into the repository source tree
