# Curriculum Structure

This directory will hold the staged curriculum for the course.

## Intended Shape

Each stage will eventually receive its own folder and stage overview. Each topic inside that stage will follow the same lesson bundle pattern so the repository remains easy to navigate and easy to extend with AI assistance.

```text
docs/curriculum/
|-- 01-foundations/
|-- 02-csharp-core/
|-- 03-productivity-and-data-transformation/
|-- 04-runtime-tooling-and-diagnostics/
|-- 05-data-and-persistence/
|-- 06-aspnetcore-foundations/
|-- 07-api-development/
|-- 08-blazor/
|-- 09-testing-and-quality/
|-- 10-performance-and-memory/
|-- 11-architecture-and-delivery/
`-- 12-capstone/
```

See `ROADMAP.md` for the stage descriptions and scope.
