# 04 Inheritance Basics

## Goal

This topic teaches the learner what inheritance means in a practical C# codebase, how base and derived types relate, and why inheritance should be used carefully instead of by default.

By the end of the topic, the learner should be able to:

- explain what it means for one type to derive from a base type
- define a small abstract base class with shared members
- override base behavior in a derived type
- explain when inheritance is appropriate and when composition is usually the safer choice
