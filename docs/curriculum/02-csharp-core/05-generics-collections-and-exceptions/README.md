# 05 Generics Collections And Exceptions

## Goal

This topic teaches the learner how generics keep reusable code type-safe, how collections support different access patterns, and how exceptions protect boundaries when invalid data or invalid operations appear.

By the end of the topic, the learner should be able to:

- explain why generic classes and methods remove duplication without falling back to `object`
- choose between `List<T>`, `Dictionary<TKey, TValue>`, and `HashSet<T>` based on lookup and uniqueness needs
- throw standard exceptions when callers pass invalid input or attempt invalid operations
- catch exceptions at the application boundary and turn them into clear output or user feedback
