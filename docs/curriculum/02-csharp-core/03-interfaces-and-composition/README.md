# 03 Interfaces And Composition

## Goal

This topic teaches the learner how interfaces define shared behavior contracts and how composition builds larger behavior by combining smaller objects.

By the end of the topic, the learner should be able to:

- explain what an interface promises without storing implementation details
- create two classes that implement the same interface differently
- compose those implementations into a higher-level object
- prefer composition for flexible behavior instead of forcing one large class to do everything
