# 02 Records Structs And Enums

## Goal

This topic teaches the learner how to model small data-focused types with records, when a struct is a better fit for compact value data, and how enums constrain state to a known set of named options.

By the end of the topic, the learner should be able to:

- explain the basic purpose of a record, a struct, and an enum
- choose an enum when a value should come from a small fixed set
- use a struct for a small value-oriented model
- use a record for data that benefits from concise definition and copy-with-change behavior
