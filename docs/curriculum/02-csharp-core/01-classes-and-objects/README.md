# 01 Classes And Objects

## Goal

This topic introduces object modeling with classes by showing how data and behavior can live together inside one small, purposeful type.

By the end of the topic, the learner should be able to:

- explain the difference between a class definition and an object instance
- create objects with `new` and a constructor
- use properties to read object state
- call methods that keep behavior close to the data they work on
