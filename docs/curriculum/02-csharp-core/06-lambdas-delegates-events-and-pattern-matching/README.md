# 06 Lambdas Delegates Events And Pattern Matching

## Goal

This topic teaches the learner how C# can treat behavior as data through delegates and lambdas, publish notifications through events, and branch clearly with pattern matching.

By the end of the topic, the learner should be able to:

- explain what a delegate represents and when a lambda expression is the most direct way to supply behavior
- subscribe to and raise a simple event without tightly coupling the publisher and subscriber
- use pattern matching to describe objects based on both their type and their data
- combine these tools in one small flow without hiding the control path
