# 05 Data And Persistence

This stage covers database fundamentals and practical data access in modern .NET applications.

## Outcomes

- Model relational data and reason about database queries.
- Build EF Core-based data access layers with migrations, query-shape awareness, and transaction discipline.
- Apply caching appropriately to reduce load and latency without hiding correctness issues.

## Planned Topics

- SQL fundamentals for application developers
- EF Core modeling, migrations, and transactions
- Query tuning, N+1 detection, and compiled query tradeoffs
- Caching strategies and invalidation tradeoffs
