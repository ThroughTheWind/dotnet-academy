# Start Learning

This page is the learner entry point for Dotnet Academy.

If you want to start the course without maintainer workflow noise, use this page and stay on the learner path below.

## Start Path

1. Install the .NET 10 SDK.
2. Open the [Curriculum Index](./curriculum/README.md#stage-map).
3. Start with [01 Foundations](./curriculum/01-foundations/README.md#how-to-use-this-stage) unless you already know the prerequisites.
4. Use the [Stage 1 Topic And Asset Index](./curriculum/01-foundations/README.md#topic-and-asset-index) when you want direct links to the lesson, exercises, demo, or tests.
5. For each implemented topic, move through the material in this order: overview, lesson, exercises, then demo.
6. Use labs after you finish the core topic sequence for a stage.

## How To Use This Repository Effectively

- Use `docs/curriculum/` to decide what to learn next and in what order.
- Use exercises before demos so you attempt the concept yourself before inspecting the reference solution.
- Use demos in `src/` when you want a runnable example for one topic or one integrated sample.
- Use tests when you want to understand the intended behavior of the reference implementation.
- Use labs only after you finish the core topic sequence for a stage.
- You do not need `ROADMAP.md`, `BACKLOG.md`, `CONTRIBUTING.md`, `scripts/`, or `.ai/` to begin learning.

## Asset Guide

- `docs/curriculum/` contains the learner path and stage indexes.
- `exercises/` contains learner practice tasks and starter materials.
- `src/` contains runnable demos and reference implementations.
- `labs/` contains integrated learner projects with `starter/` and `solution/` assets when both are present.
- `tests/` contains automated verification for the runnable demos and integrated reference solutions.
