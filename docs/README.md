# Start Learning

This page is the learner landing page for Dotnet Academy.

If you want to start the course without maintainer workflow noise, use this path:

1. Install the .NET 10 SDK.
2. Open the [Curriculum Index](./curriculum/README.md).
3. Start with [01 Foundations](./curriculum/01-foundations/README.md) unless you already know the prerequisites.
4. For each implemented topic, move through the material in this order: overview, lesson, exercises, then demo.
5. Use labs after you finish the core topic sequence for a stage.

## Asset Guide

- `docs/curriculum/` contains the learner path and stage indexes.
- `exercises/` contains learner practice tasks and starter materials.
- `src/` contains runnable demos and reference implementations.
- `labs/` contains integrated learner projects with `starter/` and `solution/` assets when both are present.
- `tests/` contains automated verification for the runnable demos and integrated reference solutions.

## Recommended First Steps

- New to the repository: start with [Curriculum Index](./curriculum/README.md).
- New to C#: start with [01 Foundations](./curriculum/01-foundations/README.md).
- Ready for data shaping topics: continue with [03 Productivity And Data Transformation](./curriculum/03-productivity-and-data-transformation/README.md).

## Contributor Notes

If you are editing repository content rather than learning from it, use [CONTRIBUTING.md](../CONTRIBUTING.md). Learners do not need the contributor process, branch naming rules, templates, or scaffolding scripts to begin the course.
